# 표 속 표 칸 그림 크기 조절 시험 (2026-10-06)

사용자 보고 「표 속의 이미지 크기 줄였을 때 표의 크기 자동 조절이나 다음 단락 위치 조정이 안 된다」(문항카드 2쪽 그래프 상자)를 재현하고 고친 도구다.

| 파일 | 하는 일 |
| --- | --- |
| `pic_shrink.mjs <hwpx>` | 엔진(studio-dist/node)으로 열어 표 속 표 칸의 그림을 `setCellPicturePropertiesByPath` 로 60% 로 줄인 뒤 그림 상자, 그래프 상자 높이, 다음 문단 캐럿 y 를 전후로 찍는다 |
| `pic_drag.mjs [배율]` | 보이지 않는 크로미움(`../linebreak/hold.py`)에서 그림을 눌러 고르고 오른쪽 아래 손잡이를 끌어 줄인 뒤 같은 값을 찍는다(스튜디오의 실제 끌기 경로) |
| `measure.py <hwpx...>` | hwpx 의 그림 `hp:sz`, 그림을 품은 표 속 표 `sz height`, 그림 칸 `cellSz`, 그 칸 문단들의 `vertpos` 를 찍는다. 한/글 기준 동작은 그림 `hp:sz` 만 60% 로 바꾼 사본을 `hwp_resave_many.py` 로 다시 저장해 읽었다 |

실측
- 한/글 2024: 그림 21494 → 12896 이면 안쪽 상자 24976 → 16378, 다음 문단 vertpos 23694 → 15096(그림 높이 차만큼), 바깥 표(글자처럼 취급 아님) 66825 그대로
- 고치기 전 엔진: 그림만 작아지고 상자 333px, 다음 문단 y 788.3 그대로(그림은 칸 가운데 정렬이라 아래로 내려감). 글을 넣으면 커지지만 지워도 안 줄었다
- 고친 엔진(스킬 `patches/cell-pic-resize-nested.rs`, `nested-sync-nontac.rs`): 상자 218.4px(= 16378), 120% 면 390.3, Enter 3회 + 글 3줄 497.0, 글 지움 454.3. 에디터 끌기 60%: 상자 219, 다음 문단 731.3

원인 둘: ① 경로 판 그림 속성 설정의 줄 다시 나누기 보정이 1단 칸에만 있었다 ② 안쪽 표 다시 재기(`tac-nested-sync`)가 쪽 나누기 앞 맞춤에서 글자처럼 취급 바깥 표에만 불렸다
