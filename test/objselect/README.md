# 개체 선택 시험 (2026-10-06)

메모 패널이 그림, 표 개체 선택에 영향을 주는지 묻는 사용자 질문에 답하려고 만든 도구다. 보이지 않는 크로미움(`../linebreak/hold.py`, CDP 9333)에서
`cli.mjs start --no-browser` 로 연 문서에 마우스 클릭을 보내 선택 결과를 읽는다. 쪽 좌표는 엔진 `getPageControlLayout(쪽)` 에서, 화면 좌표는
`getPageLeftResolved`, `getPageOffset` 과 iframe 자리로 계산한다.

| 파일 | 하는 일 |
| --- | --- |
| `obj_select.mjs list` / `run [closed]` | 쪽마다 개체 목록 / 메모 패널 열림과 닫힘을 네 번 번갈아 그림 가운데, 표 왼쪽 선, 칸 안을 눌러 결과(그림, 표, 커서)를 비교 |
| `obj_layers.mjs` | 같은 초기 상태(Esc, 1쪽 글 누르기)에서 그림을 누른 뒤 선택 층(그림 손잡이, 표 개체 층)의 조각 좌표를 쪽 좌표로 비교 |
| `obj_stale4.mjs <라벨> <쪽>` | 그 쪽의 본문 표 왼쪽 선을 눌러 표 개체 선택 상자 수를 세고, 그 상태에서 그래프 그림을 눌러 그림이 선택되는지, 1쪽 글을 누르면 상자가 지워지는지 |

실측 결과(문항카드_이산화탄소_261002_03_안유민메모 사본)
- 메모 패널 열림과 닫힘에서 그림 선택, 본문 표 선택, 칸 안 커서가 모두 같다(선택 상자 좌표도 쪽 좌표로 같음). 패널은 영향이 없다
- 메모와 무관한 결함: 3쪽 본문 표(문단 7, 컨트롤 0)를 고르면 2쪽 그래프 상자(표 속 표, 칸 안 문단 7, 컨트롤 0)에도 선택 상자가 생기고, 그 상태에서 그래프 그림을 누르면 그림이 선택되지 않았다. 번호가 겹치지 않는 1쪽 표는 정상.
  엔진 번호 조회가 표 속 표를 같은 번호로 집은 것 → 스킬 `patches/nested-table-skip-*.rs`(최외곽 표만). 고친 뒤 상자 하나, 그림 선택됨
- 미확인: 표 속 표 속 표(깊이 3)의 왼쪽 선을 누르면 안쪽 표 선택이 아니라 바깥 칸에 커서가 놓인다(고치기 전후 같음, 클릭 좌표가 선 위 허용 범위 밖일 수 있음)
- 함정: 첫 실행 직후의 첫 한 바퀴는 결과가 흔들린다(문서를 연 직후). 두 바퀴 이상 돌려 비교한다
