# HWPX 기본 디자인 원칙

새 문서를 만들 때 따르는 기본 디자인이다. 도구는 `scripts/md2hwpx_design.py`(마크다운 → 디자인 입힌 hwpx).
2026-10-01 연구정보원 제출용 학습지 8종을 만들며 정했고, 사용자가 「늘 만드는 기본 표보다 예쁘다」고 확인했다.

## 사용자 선호

- **알록달록한 것을 좋아하지 않는다.** 기본은 무채색에 가까운 한 가지 강조색(`ink` 먹색, 또는 `slate` 회청색)이다.
- 과목별, 행사별로 색을 나누는 것은 **사용자가 요청할 때만** 한다(`teal`, `orange`, `purple` 등).
- 디자인은 상황마다 다르다. 이 원칙은 출발점이지 정답이 아니다. 문서 성격에 맞춰 조정하되 조정한 내용을 알린다.

## 원칙 여섯

| 항목 | 기본값 | 이유 |
|---|---|---|
| 색 | 강조색 하나 + 그 색을 흰색에 90% 섞은 옅은 색 | 색은 꾸밈이 아니라 위계를 나타내는 데만 쓴다. 두 가지 넘는 색은 산만하다 |
| 위계 | 제목 배너(17pt, 흰 글자) > 절 제목 띠(12.5pt, 강조색 글자, 왼쪽 1mm 선) > 표 머리(10pt 굵게) > 본문(10pt) | 크기와 바탕 네 단계면 한 장짜리 문서의 구조가 한눈에 보인다 |
| 선 | 표 선은 회색 0.12mm, 바탕색은 표 머리에만 | 검은 선과 전면 바탕은 무겁다. 내용 칸은 비워 둔다 |
| 글꼴 | 맑은 고딕 하나 | 바탕체와 섞으면 인쇄물이 낡아 보인다. 강조는 굵기로 한다 |
| 여백 | 절 제목 앞에 빈 줄 하나, 본문 문단 내어쓰기 없음 | 절 사이 숨 쉴 자리. 내어쓰기는 둘째 줄을 들여 학습지에서 어색하다 |
| 쪽 나눔 | 절 제목과 바로 뒤 안내 문장은 다음 문단과 함께. 짧은 표(15행 이하)는 나누지 않음 | 제목이 쪽 끝에 홀로 남거나 표가 두 쪽에 걸치면 인쇄물이 망가진다 |

## 쓰기 칸

학습지는 학생이 쓰는 자리가 핵심이다. 밑줄(`____`)보다 **테두리 있는 칸**이 쓰기 편하다.
md 표 셀에 `<br>` 를 이어 쓰면 그 줄 수만큼 높이가 생긴다.

```markdown
| 가 보고 싶은 곳과 그 까닭 |
| --- |
| <br><br><br> |
```

칸 머리(표 머리)에 무엇을 쓰는지 적어 두면 따로 안내 문장이 필요 없다.

## 이름 줄

학년, 반, 번, 이름을 적는 줄은 **오른쪽 정렬**이 관례다(사용자 확인). 단 오른쪽 끝에 「이름:」이 딱 붙어 쓸 자리가
없으면 안 된다. 스크립트가 「이름」이 든 짧은 줄(「이름:」, 「이름 ___」, 또는 학년, 반, 번, 모둠과 함께 쓰인 줄)을 찾아
오른쪽 정렬하고, 「이름:」 뒤가 비었거나 짧으면 밑줄 14자로 채운다. 이미 이름이 적혀 있으면(교사용 예시) 그대로 둔다.

```markdown
5학년 (　　)반 (　　)번 이름:
```

반, 번 괄호 안에는 전각 공백 두 칸 이상을 넣어 숫자 쓸 자리를 둔다. 이름 줄 아래에는 빈 줄 하나를 둔다(스크립트가 넣는다, 사용자 확인).

## 학생용에는 학생에게 필요한 것만

「과학 5학년 4단원 「우리 몸의 구조와 기능」 서술형 평가 연계 학습지 (CER 서술형, 80점 만점)」 같은 **교사용 설명 줄은 학생용에서 뺀다**(사용자 지시). 제목 배너 다음은 바로 이름 줄이다. 단원, 차시, 평가 방식, 출처 같은 정보는 교사용이나 파일명에 둔다. 학생이 읽어야 하는 안내(무엇을 하는지, 어떻게 쓰는지)만 남긴다.

## 어디에 쓰고 어디에 쓰지 않나

| 쓴다 | 쓰지 않는다 |
|---|---|
| 학습지, 평가지, 활동지, 안내문, 가정통신문 본문, 연수 자료 요약, 체크리스트, 회의 자료 한두 쪽 | 공문, 기안문, 계획서처럼 **행정 서식 규범**이 있는 문서(`gonmun` 템플릿, `official-doc-style.md`) |
| | **사용자가 준 양식**이 있는 문서(워크플로 F, 양식 채우기) — 양식의 디자인이 정답이다 |
| | 수십 쪽짜리 보고서(표지, 목차, 섹션 바가 필요하면 `government` 템플릿) |

## 만든 뒤 알릴 것

결과를 전할 때 한두 줄로 디자인을 알려 준다. 사용자가 고르거나 바꿀 수 있게 하는 것이 목적이다.

> 디자인: `ink`(먹색) 한 가지 색. 제목 배너, 절 제목 띠, 표 머리 바탕. 맑은 고딕.
> 바꾸려면 `slate`(회청색)나 과목별 색도 된다.

## 한계

- 제목(`#`)과 절 제목(`##`)을 한 칸짜리 표로 바꿔 입히므로, 한글의 개요 번호나 차례 자동 생성에는 잡히지 않는다. 차례가 필요한 긴 문서에는 쓰지 않는다.
- 이모지는 글꼴에 따라 빈 네모로 나온다. 원고에서 뺀다.
- 표 열 너비는 md2hwpx 의 내용 비례 배분을 따른다. 짧은 칸이 좁아 줄바꿈되면 표를 나누거나 긴 설명을 표 밖 목록으로 뺀다.
